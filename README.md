# 出海视频（内部 Mac 工具，0.2.0）

这是原生 macOS `.app`，无需浏览器、服务器或寻找旧 Codex 对话。目标是把已验证的 Stable3 加工链、对标研究和外盘素材库收进一个单任务工具。当前是**内测试用版**，不是已完成的一键出海产品。

## 当前真实可用

- 从 Mac 文件选择器选中文视频；应用内核对物理外盘挂载与 UUID、剩余空间、冻结 Stable3 发布包与运行时。内盘低于 20 GiB 时禁用重媒体操作；读取历史成片、轻量索引与选材不因此禁用。
- 在预检允许时，依次执行冻结包完整性、环境、固定语音回归和 `prepare_workspace.py`，为源片建立外盘独立工作区。准备不等于译稿获批或成片。
- 关键词搜索 B站、YouTube 的公开视频元数据；抖音可人工保存链接。收藏只保存标题和来源，不自动下载视频。
- 导入自有录屏、MUSE 生成或获授权的图片/视频到外盘候选库，校验 SHA-256，保留来源与授权说明。候选不等于可发布。
- 已入库素材有稳定 ID、中文名称与镜头标签；可搜索并为一个镜头选择 1–2 件，哈希复核后生成取用清单。当前直接引用外盘媒体，不制造内盘副本。
- 素材库显示真实缩略图、图片/视频预览；可改名称与标签；选中的两件素材可交给现有「口播制作」原生工具，接收端复核哈希并保存选材记录。
- 可打开已有 Stable3 工作区，查看完整英文稿、验证报告与步骤状态。批准需要实际翻译模型信息、用户确认和匹配的稿件摘要；成片制作仍执行原管线和质量门。完成期次只读取，不重复渲染。
- 最近工作区、阶段日志与中断恢复引用保留；可停止本次任务并结束其子进程组。两个视频工具共享制作锁，避免并行占用重型资源。ASR/TTS/转码使用原有资源预检与低优先级外盘日志/临时文件。
- 2026-10-01 已启动 MUSE 第二批素材任务及本线程持续补库。工具新增「接收 MUSE 素材包」：只接收外盘 ZIP，核对路径、体积、INDEX、实际媒体流和哈希，按批次原地建卡，重复接收不复制。方法与批次状态见 `MUSE_ASSET_OPERATIONS.md`；尚在云端生成或聊天里的附件不算外盘资产。

2026-10-01：B01六件原件已收齐、B02六件和R02两件修正版已入库，共14件独立素材，均核对SHA/媒体流。B02键鼠摆放、封箱多手问题旧版保留并禁选；R02鼠标布局静帧已实际预览，封箱全6秒每半秒抽查12帧未见第三只手。B03六件新类别生成中未计数。全量仍是待本期适用性与完整动态确认的候选，用户商用声明保留，不把技术入库当公开发布接受。

## 明确未完成

- 新视频英文稿自动起草尚未接入。验证、明确审批与最终制作的按钮和原命令已接入，但本轮因内盘约 7 GiB **没有运行新的源片端到端制作**，不把单元测试当成媒体验收；完整人耳审看仍单独确认。
- 无中文视频时的自动二创文案/分镜/中文视频渲染，以及按需录屏。
- 抖音稳定的工具内搜索接口、第三方视频授权文件与每条素材的范围映射。
- 云端上传、远程哈希回读、按需下载与缓存回收；接口和验收边界见 `CLOUD_ASSETS.md`，当前所有卡片为 `not_uploaded`。

这些阶段不会由“准备工作区”按钮偷跑，也不会显示虚假完成状态。固定 QiuGe 声线只用于有授权的内部现有工作流，不能当作任意客户音色。

## 构建和检查

```sh
zsh build.sh
python3 -m unittest discover -s tests -v
python3 Sources/video_tool.py doctor
```

安装包：`dist/出海视频.app`（本机临时签名，未公证，未在其他 Mac 验证）。运行时和素材外接盘是当前机器依赖；源码及轻量 App 留在内置盘。外接盘素材目录见工具首页。

桌面已有「出海视频（内测）.app」入口指向本构建。验收与未验证项见 `ACCEPTANCE-20261001.md`。没有安装常驻服务、本地大模型或全天录屏。
